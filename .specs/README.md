# Specs

One file per feature, numbered in the order we built them: `N-short-name.md`.

Each spec is minimal and answers three questions:

- **Task** — what we set out to do, in a sentence or two.
- **Why** — the problem or motivation behind it.
- **How** — the implementation approach: components, key decisions, what we deliberately left out.

Write the spec before (or while) building the feature; update it if the approach changes.
